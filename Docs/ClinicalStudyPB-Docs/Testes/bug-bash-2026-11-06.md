# Bug bash da Release 1 (06/11/2026)

Sessão do feature freeze em que todo o time usa o sistema procurando defeitos antes da entrega de 10/11. Cada bug vira um card no Azure DevOps, e a líder da sprint (Mirelle) distribui.

## Como participar

1. Suba o ambiente: `docker compose up -d --build` (web em `http://localhost:3000`).
2. Use as contas da migração V2 (senha `Senha@123`): `admin@`, `pesquisador@`, `coordenador@` e `participante@clinicalstudypb.test`.
3. Cada pessoa fica com uma área e depois troca:

| Área | O que testar | Perfil |
| --- | --- | --- |
| Login e perfis | RF02 e RF03, seguindo o [roteiro de regressão](roteiro-regressao-rf01-rf04.md) | todos |
| Usuários | RF01 | ADMINISTRADOR |
| Estudos | RF04 | PESQUISADOR |
| Candidatos | RF08: listar, filtrar, cadastrar e editar | COORDENADOR |
| Consentimento e inclusão | RF10 e RF11: registrar, incluir, vagas esgotadas e candidato inelegível | COORDENADOR |
| API | RF05, RF06 e RF09 pelo contrato OpenAPI (sem tela na web) | PESQUISADOR e COORDENADOR |

4. Achou um problema? Antes de abrir o card, confira na tabela abaixo se já não foi registrado.

## Modelo do card (Azure DevOps, tipo Bug)

```text
Título: [Tela ou rota] O que acontece de errado, em uma frase
        ex.: [Candidatos] Contador mostra "1 livres" com uma vaga sobrando

Perfil usado: COORDENADOR
Ambiente: Docker Compose, develop no commit <hash>, navegador <nome e versão>

Passos para reproduzir:
1. ...
2. ...
3. ...

Resultado esperado: ...
Resultado obtido: ...

Severidade: Crítica | Alta | Média | Baixa
Evidência: print ou vídeo anexado (e o erro do console ou a resposta da API, se houver)
```

### Severidade

| Nível | Quando usar | Exemplo |
| --- | --- | --- |
| Crítica | Bloqueia o fluxo principal ou expõe dado/rota para o perfil errado | Pesquisador consegue incluir candidato |
| Alta | Funcionalidade de um RF não funciona, sem alternativa | Cadastro de estudo não salva |
| Média | Funciona, mas com regra ou mensagem errada | Mensagem de erro genérica no lugar da específica |
| Baixa | Texto, layout ou detalhe visual | Acento faltando, botão desalinhado |
