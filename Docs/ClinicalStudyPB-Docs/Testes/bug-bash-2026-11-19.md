## 4. Modelo de registro de defeito

```text
Título: [Tela ou rota] O que acontece de errado, em uma frase
        ex.: [Candidatos] Status do participante não é atualizado após inclusão

Perfil usado: COORDENADOR
Ambiente: Docker Compose, develop no commit <hash>, navegador <nome e versão>

Passos para reproduzir:
1. ...
2. ...
3. ...

Resultado esperado: ...
Resultado obtido: ...

Severidade: Crítica | Alta | Média | Baixa
Evidência: print ou vídeo anexado (e erro no console ou resposta da API, se houver)
```

### 4.1. Severidade

| Nível | Quando usar | Exemplo |
| --- | --- | --- |
| Crítica | Bloqueia fluxo principal ou expõe acesso indevido | Pesquisador inclui candidato sem permissão |
| Alta | Funcionalidade principal não funciona | Cadastro de estudo não salva |
| Média | Funcionamento parcial ou mensagem errada | Mensagem genérica em vez da específica |
| Baixa | Texto, layout ou detalhe visual | Botão desalinhado ou texto inconsistente |
